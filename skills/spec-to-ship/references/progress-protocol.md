# 进度声明协议（防"跑着跑着忘了"）

> 解决的问题：skill 之间不会互相调用，没有任何机制强制我去读下一步。
> 唯一能约束的，是**每轮都公开声明"我在哪、下一步读谁"**，让跳过变得可见。

---

## 一、每轮回复必须带进度头

凡在跑案子流程中，回复（含中途汇报）开头加一行：

```
▸ ④/⑦ 消息与协议 ｜ 已读 feishu-spec §3-5 ｜ 下一步 game-message-protocol ｜ 门禁：3 个待删字段
```

四段固定，缺一段就是没声明：

| 段 | 写什么 | 不写的后果 |
|---|---|---|
| **阶段** | `当前/总阶段` + 阶段名 | 不知道自己走到哪 |
| **已读** | 这步依据哪个文件的哪一节 | 凭记忆做，规则漂移 |
| **下一步** | 接下来要读谁 / 调谁 | 断链 |
| **门禁** | 本阶段过关条件 + 目前是否满足 | 带病进下一步 |

**轻档不强制**（但至少写阶段）。
**重档每轮必写**；中档在阶段切换时写。

---

## 二、状态文件：`.tmpfiles/<功能>/PROGRESS.md`

每阶段**切换时**必须更新，不是每轮。

```markdown
# 进度：<功能名>

- 档位：重
- 案子：<链接>（revision / 读取日期）
- 代码根：<路径>
- 当前阶段：④ 消息与协议
- 已完成：① 读案 ｜ ② 需求清单 ｜ ③ 字段映射
- 本阶段门禁：未过 —— 3 个字段答不出"客户端为什么不能算"
- 下一步读：`game-message-protocol`
- 阻塞：无
- 未决：Q-03 增益道具数值口径（等策划）
- 更新时间：`<填写>`
```

### 更新时机（五个检查点）

1. **阶段切换**：进下一步前写一次
2. **被阻塞**：写清卡在哪、等谁
3. **派 agent 前**：写清这次派谁、要什么产出
4. **收 agent 后**：写清拿了什么、是否达标
5. **每次交付/中断前**：写清已验证 / 未验证

### 恢复时怎么用

用户第二天说"继续"：

1. 先读 `PROGRESS.md`
2. 从"当前阶段"接着做，**不重读前面已完成的部分**
3. 如果"未决"里有已解决的问题，先划掉再继续

---

## 三、阶段编号对照（只认一套）

| 编号 | 名称 | 主责文件 |
|---|---|---|
| ① | 读案 | 本 skill §3① + `workflow.md` S1 |
| ② | 需求清单 | 本 skill §3② + `workflow.md` S2–S3 |
| ③ | 字段映射 | `spec-driven-dev` §2 |
| ④ | 消息与协议 | `spec-driven-dev` §3–5 + `game-message-protocol` |
| ⑤ | 实现 | `spec-driven-dev` §6–7 + `code-quality.md` + `codebase-pitfalls.md` |
| ⑥ | 自检 + 审查 | 本 skill §3⑥ + `spec-driven-dev` §8–9 + `game-code-review` |
| ⑦ | 验收 + 交付 | 本 skill §3⑦ + `adversarial-gameplay-acceptance` |

**三套编号的废弃说明**：
- `workflow.md` 里的 S0–S11 是**步骤细目**，不是阶段编号，引用时说"S4（=③）"
- `gates.md` 里的 G0–G7 是**重档门禁名**，同样只说"G1.5（=③）"
- **对用户只报 ①–⑦**，避免三套编号打架

---

## 四、跳步必须显式申请

想跳过某阶段（例如案子太简单，不填五张表），必须写：

```
▸ 跳过 ③ 字段映射 —— 理由：本案无界面字段，全部为服务端逻辑
```

**未经声明的跳过 = 违规。** 用户看到没声明就跳，可以直接打回。

### 允许跳的

| 阶段 | 什么情况下可跳 |
|---|---|
| ③ 字段映射 | 案子无 UI、无表头、无字段清单 |
| ④ 协议 | 纯服务端逻辑，不涉及客户端 |
| ⑥ 玩家预演 | 无玩家可见界面 |

### 不允许跳的

① 读案（除非轻档且需求已在对话里说全）
⑦ 覆盖对账

---

## 五、门禁不过时的三种正确处理

| 情况 | 做法 |
|---|---|
| 能自己补 | 补完重跑门禁，不前进 |
| 需要外部输入 | 记进 `PROGRESS.md` 的"未决" + `缺口清单.md`，**标为阻塞后继续能做的部分** |
| 阻塞主流程 | 停下来报告，不硬推 |

**禁止**：门禁没过的状态下写"已完成"。

---

## 六、自检三问（每次说"完成"前）

1. **我这一步读的是哪个文件的哪一节？** 说不出 = 凭记忆做的。
2. **门禁条件我逐条对过了吗？** 对不出 = 没过。
3. **`PROGRESS.md` 更新了吗？** 没更新 = 中断后接不上。

---

## 七、一句话

> **每轮报阶段，每阶段写检查点，跳步要申请，门禁不过不许说完成。**
